# Tag `#system`

## 🏷️ 1. What is the `#system` tag?

<details>
<summary>View details</summary>

<br>

The **#system** tag is used to mark posts related to **how KnowledgeHub is organized and operated**.

It includes articles on:

* Information management rules (e.g., metadata)
* Classification structure (e.g., tags)
* Directory/file structure, detailed in [#structure](/.hub/nav/tag/structure.vi.md)
* System operating principles

Articles with this tag serve as **guidance**, helping to ensure:

* A clear overview
* Links between components
* Scalability and long-term development

```
#system
│
├── #structure
│ └── Directory/file structure
│
├── Metadata
│
├── Classification structure
│
└── Process
```
