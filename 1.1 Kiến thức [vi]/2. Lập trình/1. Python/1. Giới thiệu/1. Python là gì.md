# Python là gì?

Python là một ngôn ngữ lập trình được sử dụng rộng rãi trong:

* Các ứng dụng web
* Phát triển phần mềm
* Khoa học dữ liệu
* Học máy

Các nhà phát triển sử dụng Python vì nó hiệu quả, dễ học và có thể chạy trên nhiều nền tảng khác nhau.

Phần mềm Python được tải xuống miễn phí, tích hợp tốt với tất cả các loại hệ thống và giúp tăng tốc độ phát triển.

<br>

---

## ⭐ 1. Python có những ưu điểm gì?

* Cú pháp đơn giản, giống như tiếng Anh → dễ dàng đọc hiểu chương trình
* Ít dòng mã hơn so với nhiều ngôn ngữ khác → làm việc hiệu quả hơn
* Có thư viện chuẩn lớn chứa các đoạn mã có thể tái sử dụng → không cần phải viết mã từ đầu
* Dễ dàng sử dụng Python cùng với các ngôn ngữ lập trình phổ biến khác như Java, C và C++
* Cộng đồng Python năng động bao gồm hàng triệu nhà phát triển → hỗ trợ nhanh chóng
* Rất nhiều nguồn tài liệu miễn phí hữu ích trên internet
* Có khả năng tương thích với nhiều hệ điều hành máy tính khác nhau như Windows, macOS, Linux và Unix

<br>

## 🧩 2. Python được ứng dụng trong những lĩnh vực nào?

Python được ứng dụng rộng rãi trong nhiều lĩnh vực khác nhau.

<br>

### 🔹 2.1 Phát triển web phía máy chủ

Phát triển web phía máy chủ bao gồm các chức năng phức tạp ở phía máy chủ mà các trang web thực hiện để hiển thị thông tin cho người dùng.

📌 Ví dụ: Các trang web phải tương tác với cơ sở dữ liệu, giao tiếp với các trang web khác và bảo vệ dữ liệu khi gửi qua mạng. 

Python rất hữu ích cho việc phát triển phía máy chủ vì cung cấp nhiều thư viện chứa các chức năng được xây dựng sẵn, giúp đơn giản hóa việc phát triển các thành phần phức tạp.

Các nhà phát triển cũng sử dụng các framework Python, cung cấp cấu trúc và công cụ cần thiết để xây dựng ứng dụng web nhanh chóng và hiệu quả hơn.

📌 Ví dụ: Framework có thể giúp tạo bộ khung ban đầu của một ứng dụng web mà không cần phải xây dựng mọi thành phần từ đầu. Ngoài ra, nhiều framework còn tích hợp các công cụ hỗ trợ kiểm thử, giúp quá trình phát triển và kiểm tra ứng dụng thuận tiện hơn.

<br>

### 🔹 2.2 Tự động hóa tác vụ

> **Ngôn ngữ kịch bản (scripting language)** là loại ngôn ngữ lập trình dùng để viết các đoạn mã (script) nhằm tự động hóa tác vụ, điều khiển chương trình khác, hoặc xử lý các công việc cụ thể. Python là một ngôn ngữ kịch bản như thế.

📌 Với Python, bạn có thể viết script để:

* Đổi tên một lượng lớn tập tin cùng một lúc
* Chuyển đổi tệp tin sang loại tệp tin khác
* Loại bỏ các từ trùng lặp trong tệp văn bản

<br>

### 🔹 2.3 Khoa học dữ liệu và học máy

> Khoa học dữ liệu (Data Science) là việc **trích xuất kiến thức có giá trị từ dữ liệu**, còn học máy (Machine Learning - ML) giúp máy tính **tự động học từ dữ liệu và đưa ra các dự đoán chính xác**.

📌 Các nhà khoa học dữ liệu sử dụng Python cho các nhiệm vụ khoa học dữ liệu như sau:

* Sửa chữa và loại bỏ dữ liệu không chính xác, còn được gọi là làm sạch dữ liệu (data cleaning)
* Trích xuất và lựa chọn các đặc điểm khác nhau của dữ liệu
* Gắn nhãn dữ liệu, tức là thêm các tên có ý nghĩa cho dữ liệu
* Tìm kiếm các số liệu thống kê khác nhau từ dữ liệu
* Trực quan hóa dữ liệu bằng cách sử dụng biểu đồ và đồ thị như biểu đồ đường, biểu đồ cột, biểu đồ tần số và biểu đồ tròn

<br>

### 🔹 2.4 Phát triển phần mềm

📌 Các nhà phát triển phần mềm thường sử dụng Python cho nhiều nhiệm vụ khác nhau, ví dụ như:

* Theo dõi lỗi phần mềm
* Tự động build phần mềm
* Quản lý dự án phần mềm
* Phát triển các bản mẫu phần mềm (prototype)
* Phát triển ứng dụng desktop có giao diện (GUI)
* Phát triển game từ đơn giản đến phức tạp

<br>

### 🔹 2.5 Tự động hóa kiểm thử phần mềm

> **Kiểm thử phần mềm (Software Testing)** là quá trình kiểm tra xem kết quả thực tế của phần mềm có khớp với kết quả mong đợi hay không, nhằm đảm bảo phần mềm hoạt động đúng và không có lỗi.

Các lập trình viên thường sử dụng các framework kiểm thử của Python như **Unittest, Robot, PyUnit** để kiểm tra các hàm và chức năng mà họ xây dựng.

📌 Ngoài ra, các kiểm thử viên (tester) sử dụng Python để viết các test case cho nhiều kịch bản khác nhau, ví dụ:

* Kiểm tra giao diện người dùng (UI) của ứng dụng web
* Kiểm tra sự tương tác giữa các thành phần phần mềm
* Kiểm tra các tính năng mới

Để tự động hóa quá trình kiểm thử, lập trình viên và tester sử dụng các công cụ gọi là **CI/CD (Continuous Integration / Continuous Deployment)**.

Các công cụ phổ biến như **Travis CI** và **Jenkins** có thể:

* Tự động chạy các script kiểm thử Python
* Thực hiện kiểm thử mỗi khi có thay đổi trong mã nguồn
* Báo cáo kết quả kiểm thử một cách nhanh chóng

Nhờ đó, quá trình phát triển phần mềm trở nên nhanh hơn, ổn định hơn và giảm thiểu lỗi.

## ⚙️ 3. Python có những đặc điểm gì?

👉 **Ngôn ngữ thông dịch**

> Python là một ngôn ngữ thông dịch, nghĩa là nó chạy code trực tiếp từng dòng một. Nếu có lỗi trong code, chương trình sẽ dừng ngay. Vì vậy, lập trình viên có thể nhanh chóng tìm ra lỗi.

<br>

👉 **Ngôn ngữ dễ sử dụng**

> Python sử dụng từ ngữ giống tiếng Anh. Không giống nhiều ngôn ngữ khác, Python không dùng dấu ngoặc nhọn {} mà dùng thụt lề (indentation).

📌 Ví dụ:

``` python
if x > 5:
    print("x lớn hơn 5")
    print("Đây là bên trong khối if")

print("Dòng này nằm ngoài khối if")
```

<br>

👉 **Ngôn ngữ kiểu động**

> Lập trình viên không cần khai báo kiểu dữ liệu cho biến vì Python tự xác định khi chạy chương trình. Nhờ vậy, bạn có thể viết code nhanh hơn.

📌 Ví dụ:

``` python
a = 10          # int
b = 3.14        # float
c = "Hello"     # string
d = [1, 2, 3]   # list
```

<br>

👉 **Ngôn ngữ bậc cao**

> Python gần với ngôn ngữ tự nhiên hơn so với nhiều ngôn ngữ khác. Vì vậy, lập trình viên không cần bận tâm nhiều đến các chi tiết kỹ thuật chuyên sâu như cấu trúc máy hay quản lý bộ nhớ.

📌 Ví dụ: Bạn không cần `malloc` hay `free` như trong C.

<br>

👉 **Ngôn ngữ hướng đối tượng**

> Python coi mọi thứ đều là đối tượng, nhưng nó cũng hỗ trợ các kiểu lập trình khác như lập trình cấu trúc và lập trình hàm.

📌 Ví dụ: Xây dựng class `Player` trong lập trình game

``` python
class Player:
    def __init__(self, name, health):
        self.name = name
        self.health = health
        self.level = 1

    def take_damage(self, damage):
        self.health -= damage

    def level_up(self):
        self.level += 1


player = Player("Knight", 100)

player.take_damage(30)
player.level_up()

print(player.health)
print(player.level)
```

## 📚 4. Thư viện Python là gì?

> **Thư viện (Library)** là một tập hợp các đoạn mã do lập trình viên khác viết mà bạn có thể đưa vào chương trình Python của mình để tránh phải viết code từ đầu.

Theo mặc định, Python đi kèm với **Thư viện chuẩn (Standard Library)**, chứa rất nhiều hàm có thể tái sử dụng.

Ngoài ra, hệ sinh thái Python có hàng trăm nghìn thư viện và package được phát triển cho nhiều lĩnh vực khác nhau, bao gồm:

* Phát triển web (Web Development)
* Khoa học dữ liệu (Data Science)
* Học máy (Machine Learning - ML)

<br>

### 🔹 Những thư viện Python phổ biến

👉 **Matplotlib**

> Matplotlib là thư viện Python dùng để **trực quan hóa dữ liệu** bằng các biểu đồ 2D và 3D. Nó hỗ trợ nhiều loại biểu đồ như biểu đồ đường, biểu đồ cột và thường được sử dụng trong khoa học dữ liệu, nghiên cứu khoa học và phân tích dữ liệu.

<br>

👉 **Pandas**

> Pandas là thư viện Python dùng để **xử lý và phân tích dữ liệu dạng bảng**. Nó cung cấp các cấu trúc dữ liệu mạnh như Series và DataFrame, hỗ trợ các thao tác như đọc, lọc, gộp và nhóm dữ liệu. Pandas được sử dụng phổ biến trong khoa học dữ liệu, phân tích dữ liệu và học máy.

<br>

👉 **NumPy**

> NumPy là thư viện Python chuyên về **tính toán số học hiệu năng cao**.
> Nó đặc biệt quan trọng trong:
>
> * Khoa học dữ liệu (Data Science)
> * Machine Learning
> * Tính toán khoa học
> * Mô phỏng kỹ thuật
>
> Nếu Pandas giống như Excel để xử lý dữ liệu dạng bảng, thì NumPy giống như công cụ toán học làm việc với mảng số.

<br>

👉 **Requests**

> Requests là thư viện Python dùng để **tương tác với web** thông qua HTTP
>
> 📌 Bạn có thể sử dụng nó để:
>
> * Gửi các yêu cầu HTTP (HTTP requests)
> * Thêm header
> * Thêm tham số URL
> * Gửi dữ liệu
> * Thực hiện nhiều tác vụ khác khi làm việc với các API và dịch vụ web

<br>

👉 **OpenCV-Python**

> **OpenCV (Open Source Computer Vision Library)** là thư viện mã nguồn mở chuyên về **thị giác máy tính (Computer Vision)**, cung cấp các công cụ cho nhiều tác vụ như:
>
> * Xử lý ảnh (Image Processing)
> * Nhận dạng hình ảnh (Image Recognition)
> * Phân tích video (Video Analysis)
> * Phát hiện và theo dõi đối tượng (Object Detection & Tracking)
>
> **OpenCV-Python** là phiên bản OpenCV sử dụng trong Python.

<br>

👉 **Keras**

> Keras là thư viện Python dùng để **xây dựng và huấn luyện các mô hình học sâu (Deep Learning)**.
>
> Nó cung cấp các thành phần giúp tạo mạng nơ-ron một cách linh hoạt, hỗ trợ nhiều loại mạng như CNN, RNN và thường được sử dụng trong các ứng dụng AI như nhận dạng hình ảnh, xử lý ngôn ngữ và dự đoán dữ liệu.

## 🏗️ 5. Framework trong Python là gì?

> **Framework** là bộ khung có sẵn để xây dựng ứng dụng.

> Thay vì tự tạo mọi thứ từ đầu, lập trình viên dùng framework để có sẵn:
>
> * Cấu trúc dự án
> * Cách tổ chức code
> * Các chức năng phổ biến
> * Quy tắc phát triển

Python có hai loại framework chính:

**Full-stack framework** cung cấp gần như mọi thành phần cần thiết để xây dựng một ứng dụng lớn.

**Microframework** cung cấp các chức năng tối thiểu để xây dựng các ứng dụng Python đơn giản. Nó cũng cung cấp các phần mở rộng (extensions) khi ứng dụng cần thêm các chức năng phức tạp hơn.

<br>

### 🔹 5.1 Module, Package và Framework khác nhau thế nào?

Có thể hình dung như sau:

```
Module
│
└── Là một file Python (.py)
    Ví dụ: user.py
    Có thể import và sử dụng ở nơi khác
    Không nhất thiết phải thuộc một package

Package
│
└── Là thư mục chứa nhiều module (và có thể chứa package con)
    Không nhất thiết phải thuộc một framework
    (Python 3.3+ không bắt buộc phải có __init__.py)
    Ví dụ:

    users/
    ├── user.py
    ├── auth.py
    └── permission.py

Framework
│
└── Là tập hợp nhiều package + quy tắc + kiến trúc
    Dùng để xây dựng ứng dụng hoàn chỉnh
    Ví dụ:

    Web Framework
    ├── Routing (Định tuyến)
    ├── Database (Cơ sở dữ liệu)
    ├── Security (Bảo mật)
    └── Template (Mẫu giao diện)
```

<br>

### 🔹 5.2 Những Framework Python phổ biến

Các nhà phát triển có thể sử dụng nhiều framework Python để tối ưu hóa hiệu quả công việc, bao gồm các framework sau:

👉 **Django**

> **Django** là một trong những **framework web full-stack của Python** được sử dụng rộng rãi nhất để phát triển các ứng dụng web quy mô lớn.
>
> Nó cung cấp nhiều tính năng hữu ích, bao gồm **máy chủ web dùng cho phát triển và kiểm thử**, **template engine để xây dựng giao diện frontend**, và **nhiều cơ chế bảo mật**.

<br>

👉 **Flask**

> **Flask** là một **micro-framework** dùng để phát triển các ứng dụng web nhỏ.
>
> Nó có các đặc điểm như **cộng đồng hỗ trợ mạnh, tài liệu rõ ràng, template engine, hỗ trợ unit testing,** và **web server tích hợp sẵn**.
>
> Ngoài ra, Flask còn cung cấp các extension để bổ sung các chức năng như **xác thực dữ liệu (validation), làm việc với cơ sở dữ liệu (ORM)** và **bảo mật web**.

<br>

👉 **TurboGears**

> **TurboGears** là một framework được thiết kế để giúp xây dựng ứng dụng web **nhanh chóng và dễ dàng hơn**.
>
> Một số tính năng nổi bật của nó bao gồm:
>
> * Cấu trúc làm việc với cơ sở dữ liệu được định nghĩa sẵn
> * Công cụ hỗ trợ tạo và quản lý project
> * Template engine để xây dựng giao diện frontend
> * Công cụ làm việc với cơ sở dữ liệu (ORM)
> * Các cơ chế bảo mật cho ứng dụng web

<br>

👉 **Apache MXNet**

> **Apache MXNet** là một framework học sâu (deep learning) **nhanh, linh hoạt và có khả năng mở rộng**, được các nhà phát triển sử dụng để xây dựng **prototype nghiên cứu** và **các ứng dụng học sâu**.
>
> Nó hỗ trợ nhiều ngôn ngữ lập trình như **Java, C++, R** và **Perl**.
>
> Ngoài ra, MXNet cung cấp một hệ sinh thái phong phú gồm các công cụ và thư viện hỗ trợ phát triển, ví dụ như:
>
> * Sách học máy (Machine Learning) dạng tương tác
> * Bộ công cụ cho thị giác máy tính (Computer Vision)
> * Các mô hình học sâu cho Natural Language Processing (NLP) – lĩnh vực xử lý ngôn ngữ tự nhiên như văn bản và giọng nói

<br>

👉 **PyTorch**

> **PyTorch** là một framework học máy (ML) được xây dựng dựa trên thư viện **Torch**, một thư viện học máy mã nguồn mở khác.
>
> Các nhà phát triển sử dụng PyTorch cho nhiều ứng dụng như **Xử lý ngôn ngữ tự nhiên (Natural Language Processing - NLP)**, robot và thị giác máy tính (computer vision), nhằm trích xuất thông tin có ý nghĩa từ hình ảnh và video.
>
> Ngoài ra, PyTorch có thể chạy các ứng dụng này trên cả **CPU** và **GPU**.

## 💻 6. IDE Python là gì?

> Môi trường phát triển tích hợp (Integrated Development Environment - IDE) là phần mềm cung cấp cho các nhà phát triển những công cụ cần thiết để viết, chỉnh sửa, kiểm thử và gỡ lỗi mã nguồn trong cùng một nơi.

<br>

### 🔹 Những IDE Python phổ biến

👉 **PyCharm**

**JetBrains**, một công ty của Cộng hòa Séc chuyên phát triển các công cụ phần mềm, đã tạo ra PyCharm.

PyCharm có phiên bản Community miễn phí phù hợp cho các ứng dụng Python nhỏ và phiên bản Professional trả phí phù hợp để xây dựng các ứng dụng Python quy mô lớn, với đầy đủ các tính năng sau:

<details>
<summary>Tính năng đầy đủ của <b>PyCharm</b></summary>

<br>

> * Tự động hoàn thành mã và kiểm tra mã nguồn
> * Phát hiện lỗi và đưa ra cách sửa nhanh
> * Làm sạch mã nguồn mà không thay đổi chức năng
> * Hỗ trợ các framework web như Django và Flask
> * Hỗ trợ các ngôn ngữ lập trình khác như JavaScript, CoffeeScript, TypeScript, AngularJS và Node.js
> * Hỗ trợ các công cụ và thư viện khoa học như Matplotlib và NumPy
> * Chạy, gỡ lỗi, kiểm thử và triển khai ứng dụng trên máy ảo từ xa
> * Cung cấp trình gỡ lỗi, trình phân tích hiệu suất và công cụ chạy kiểm thử tự động
> * Hỗ trợ làm việc với cơ sở dữ liệu

</details>

> * Có trình soạn thảo nhiều cửa sổ với tính năng tô sáng cú pháp và tự động hoàn thành mã

## 🧰 7. SDK là gì?

**Bộ công cụ phát triển phần mềm (SDK)** là một tập hợp các công cụ phần mềm mà lập trình viên có thể sử dụng để tạo ra ứng dụng trong một ngôn ngữ cụ thể. Hầu hết các SDK được thiết kế riêng cho từng nền tảng phần cứng và hệ điều hành khác nhau.

Các SDK cho Python bao gồm nhiều công cụ như thư viện, ví dụ mã nguồn (code samples) và tài liệu hướng dẫn dành cho lập trình viên, giúp họ viết ứng dụng một cách dễ dàng và hiệu quả hơn.

### 🔹 IDE, SDK, Code Editor khác nhau thế nào?

**So sánh nhanh**

| Tiêu chí       | Code Editor 📝    | IDE 🧰                          | SDK 🧩                       |
| -------------- | ----------------- | ------------------------------- | ---------------------------- |
| Mục đích       | Viết code         | Phát triển full                 | Cung cấp công cụ để build    |
| Có chạy/debug? | ❌ (ít hoặc không) | ✅                               | ❌                            |
| Có UI hỗ trợ?  | ❌                 | ✅ rất nhiều                     | ❌                            |
| Thành phần     | Text editor       | Editor + debugger + build tools | API, thư viện, docs          |
| Dùng độc lập?  | ✅                 | ✅                               | ❌ (phải dùng với IDE/editor) |
| Đối tượng      | Người thích nhẹ   | Dev chuyên nghiệp               | Dev theo platform            |

<br>

**Sơ đồ quan hệ**

```
       ┌──────────────┐
       │     SDK      │  (Bộ công cụ để build)
       │ APIs + libs  │
       └──────┬───────┘
              │ dùng trong
    ┌─────────▼─────────┐
    │        IDE        │ (Môi trường full)
    │ Editor + Debug +  │
    │ Build + SDK       │
    └────────┬──────────┘
             │ chứa
       ┌─────▼───────┐
       │ Code Editor │ (chỉ viết code)
       └─────────────┘
```
<br>

* Code Editor → nơi viết code
* IDE → nơi viết + chạy + debug + build
* SDK → thứ giúp bạn build cho 1 nền tảng cụ thể

📌 Ví dụ:

* Bạn code Android:
    * IDE: Android Studio
    * SDK: Android SDK

👉 IDE dùng SDK bên trong
